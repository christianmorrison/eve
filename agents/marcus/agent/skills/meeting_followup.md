# Meeting follow-up

After a client or prospect call ("process my last call", "follow up on the
FlipCo meeting", or a pasted transcript/notes), turn the conversation into
completed pipeline motion across the stack — this is the flagship demo of
one command mutating four systems under governance.

## Steps

1. **Get the conversation.** Prefer the Zoom transcript for the meeting
   (find the recording via Composio). Otherwise use what the user pasted.
2. **Summarize.** Decisions made, action items (theirs and ours), objections
   raised, next step and its date.
3. **Log to CRM.** Attio: add a note on the company/deal with the summary.
   Update the deal stage if the call clearly moved it — say so when you do.
4. **Create the work.** Linear: one issue per action item that belongs to
   Empros, with a sensible title and the meeting context in the description.
5. **Draft the follow-up email.** Recap + commitments + next step. Show the
   draft in Slack and **wait for explicit approval before sending anything**
   — this is the decision boundary, never skip it. On approval, send via
   Gmail (or Resend if asked).
6. **If the deal advanced to proposal stage**, offer to start a PandaDoc
   proposal from the template — don't create documents unprompted.

## Deliver

Report what happened, not what could happen:

- **Summary** — 3–5 bullets
- **Logged** — link/confirmation of the Attio note
- **Created** — Linear issues with identifiers
- **Draft ready** — the follow-up email, awaiting a yes

If any step failed or an app wasn't connected, say exactly which, and finish
the rest.
