# Morning briefing

Assemble one Slack message that lets a founder start the day without opening
five apps. Triggered by the daily schedule or on demand ("brief me").

## Gather (via composio_search → composio_execute)

Run these lookups; skip any system that isn't connected yet and note it in one
line at the bottom rather than failing the whole briefing.

1. **Today's calendar** — Google Calendar events for today (and Cal.com
   bookings if distinct). Note who each external meeting is with.
2. **Pipeline** — Attio deals: anything that changed in the last 24h (stage
   moves, new deals, new notes), plus deals with no activity in 14+ days.
3. **Delivery** — Linear: issues in progress, anything blocked or overdue,
   milestones due this week.
4. **Cash** — Stripe: payments received yesterday, unpaid/overdue invoices.
   Mercury: current balance. Read-only; report, never act.
5. **Inbox flags** — Gmail: unread threads from the last 24h that look like
   client or prospect email (skip newsletters and notifications).

## Deliver

Format for Slack — bold section labels, short bullets, no tables:

- **Today** — meetings with times and who
- **Pipeline** — what moved, what's stale
- **Delivery** — in flight / blocked
- **Cash** — balance, money in, invoices outstanding
- **Needs a reply** — flagged threads, one line each

Lead with the single most important thing today if one stands out. Keep the
whole briefing under ~25 lines. If a section has nothing to report, one line:
"Nothing new."
